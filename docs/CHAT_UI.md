# UI 规范 · 「纸墨」设计系统

> 2026-10-31 全量重做。旧版是紫渐变 + 玻璃气泡 + 多层投影，长对话下字发灰、层叠过多、重点不清。
> 这一版只解决一件事：**把字托起来**。所有视觉决定都服从这一条。

## 0. 设计取向

| 维度 | 选择 | 理由 |
|---|---|---|
| 风格 | AI-Native + 极简排版（Paper & Ink） | 这个 App 是深夜长对话，屏幕 80% 是文字 |
| 底色 | 暖纸白 `#F7F6F3`（深色 `#0E0E10`） | 纯白刺眼，纯灰显脏；暖白让长文更耐读 |
| 彩色 | **只有一种**：靛紫 `#4B3FD1` | 旧版紫、粉、蓝三色并用，眼睛找不到重点 |
| 分层 | 1px 发丝线 + 留白，**不用投影** | 投影叠多了会脏，聊天记录一屏十几条就糊成一片 |
| 字 | 系统字体，16sp / 26sp 行高 | 中文行高 1.6 倍最舒服；不引入第三方字体，避免中英混排断裂 |

## 2. 页面

### 2.1 聊天页

```
┌──────────────────────────────┐
│ 头像 40 · 名字 · ● 在线      🙂 ⚙ │  56dp，白底 + 底部发丝线
├──────────────────────────────┤
│                              │
│   （纸白画布，长文阅读区）      │
│                              │
├──────────────────────────────┤
│ ( + ) [ 说点什么…        ] ( ↑ ) │  输入区
└──────────────────────────────┘
```

- **消息分组**：同一个人连续发言时，只在第一条显示「名字 · 渠道 · 时间」和头像；后续气泡贴紧（2dp），换人留 10dp。
- **气泡**：她 = 白底 + 1px 描边 + 墨色字；我 = 靛紫底 + 白字。最大宽度 302dp。
- **渠道**：`App` 不显示；网页 / QQ 显示成小胶囊，避免每条都在重复。
- **已读**：只在我这一组的最后一条下面显示「已读 ✓✓」，不是每条都挂。
- **日期**：一条细线 + 居中「今天 / 昨天 / 10月31日」，不再用白底胶囊。
- **空态**：头像 + 「还没有聊天记录」+ 三个可直接发送的开场白。
- **回到底部**：向上翻且不在底部时出现 36dp 圆钮。

### 2.2 输入区

- 单行结构：`(+)` 附件 · 输入框 · 发送/麦克风（同一位置切换）。
- 空输入时按钮是麦克风（进入语音面板）；有文字时变成靛紫发送键；等待回复时变成转圈。
- `(+)` 展开 **附件抽屉**：拍照 / 图片 / 文件 / 视频 / 定位 五个等宽方块，用动画展开，收起键盘。
- 清空输入后按钮自动变回麦克风，不需要额外入口。

### 2.3 语音面板

按住录音、松开结束。76dp 圆形按钮 + 外圈光晕（录音时），下面两行提示，底部「用键盘打字」回到文字。

### 2.4 她的状态

底部抽屉（ModalBottomSheet），不做全屏弹窗：

- 顶部头像 + 「她现在的状态」+ 刷新。
- 心情：`accentSoft` 大卡，一句话 24sp。
- 近况：关系 / 记忆 / 今天，三行 label + 一句话。
- 账户：墨色卡片，余额是唯一出现数字的地方。
- 拿不到数据时只显示一张错误卡 + 「再试一次」，10 秒超时兜底，不会一直转圈。

### 2.5 设置

整屏覆盖（不是 Dialog，避免状态栏被压一层灰），分组列表：

`声音 / 哔哩哔哩 / 服务器 / 通知 / 调试 / 关于`

- 输入框：标签在上、浅底圆角、无边框。
- 每张卡 20dp 圆角 + 发丝线；次要动作用描边按钮，只有「保存 / 试听」是实心强调色。
- 「重新配对」是红色描边，避免误触。
- 调试入口从顶栏 `🐞` 移到设置 → 调试（顶栏只留状态和设置两个图标）。

### 2.6 配对页

头像 → 「连接大肥鱼」→ 一句说明 → 地址 / 配对码 → 实心按钮 → 分隔线 → 外观 → 自启动设置 / 调试页。
（外观在配对页也放一份：还没配对时也能先选浅色/深色。）

### 2.7 外观

设置第一组 + 配对页底部各有一个三段选择：**跟随系统 / 浅色 / 深色**。

- 默认「跟随系统」，实时读 `isSystemInDarkTheme()`；
- 选中后立刻重绘，不需要重启；
- 存在 `SettingsStore.themeMode`（system / light / dark），下次启动沿用；
- 诊断页、B 站登录页同样按这个值取主题。

## 2.8 返回键

逐层收，任何一层都不再直接结束 App：

| 当前状态 | 返回键行为 |
|---|---|
| 附件抽屉展开 | 收起抽屉 |
| 语音面板 | 回到键盘输入 |
| 键盘弹起 | 收键盘（不退出） |
| 设置页 | 关闭设置，回到聊天 |
| 她的状态抽屉 | 关闭抽屉 |
| 诊断页 / B 站登录页 | 结束当前页，回到上一页（设置仍保持打开） |
| B 站登录 WebView | 先网页后退，退到底才关页 |
| 聊天页 / 配对页 | `moveTaskToBack` 收到后台，进程和前台服务都不动 |

清 Token 的两个入口（重新配对 / 退出登录）现在都要二次确认，避免手滑掉登录。

## 3. 消息类型

| 类型 | 呈现 |
|---|---|
| 文字 | 16sp 气泡，>600 字折叠 8 行 + 「展开全文」 |
| 语音 | 胶囊条：播放圆钮 + 12 根波形 + 时长 + 「转文字」（展开后显示字幕块） |
| 图片 | 230dp 宽、圆角 16、1px 描边，GIF 自动播放 |
| 视频 | 240×135，Media3 内嵌播放 |
| 文件 | 卡片：图标 + 文件名 + 大小/类型 + 「查看解析内容」 |
| B 站 | 封面 92×60 + 时长角标 + 标题 + UP 主 + 两行摘要 + 「查看视频帧」；**分享自带的「【标题-哔哩哔哩】」前缀会从气泡里去掉**，标题只由卡片承载 |
| 网页 | 图标 + 标题 + 描述 + 站点名 |

链接卡片一律放在气泡**外面**（同一侧对齐），不塞进彩色气泡里，保证彩色只代表「我说的话」。

分享到 B 站链接时，系统分享出来的原始串是「【标题-哔哩哔哩】 + 短链 + 自己的话」拼成一行。
气泡只显示**自己打的那句**，标题和封面交给卡片，顺序变成「我的话 → 卡片」，
不再出现「标题在气泡里、卡片在下面，把话夹在中间」的观感。

另外，发长视频时给模型补的收尾提示（"…左上角标着时间"）会随正文落库，
显示前统一按特征清掉，历史消息也一起修正。

## 4. 保留的行为（与旧版一致）

- 新回复逐句揭示，每 1 秒一句；历史消息不重播动画。
- 流式阶段先显示「大肥鱼 · 正在输入…」三点动画。
- 发送失败的气泡半透明 + 「重试 / 删除」。
- 打开即最新：首帧直接 `scrollToItem(0)`，键盘弹出后再贴一次底。
- 向上翻时不抢滚动，只有贴底才自动跟新消息。
- 图片 / GIF / 视频 / B 站元数据的内存与磁盘缓存策略不变。
