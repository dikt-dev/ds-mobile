# 聊天页 UI 调整

> 日期：2026-10-25

## 1. 气泡

- 用户消息右对齐，浅紫气泡；
- AI 消息左对齐，白色气泡；
- 最大宽度 300dp，不再整行铺满；
- 圆角按发送方向收角（类似微信/QQ）；
- 每条消息显示：发送者 · 渠道 · 时间；
- 消息间距 12dp，聊天区浅灰背景。

截图：

- `screenshot-chat-ui.png`

## 2. 文字与语音分离

- 普通文字不再显示「朗读」；
- 内容含 `[语音]` / `（语音）` 时，按标记切分：
  - 标记前的文字 → 独立文字气泡；
  - 标记后的内容 → **独立语音条**；
- 只有 `[语音]` 的回复不再把转写文字塞进同一个气泡。

## 3. 语音条

- 类似 QQ：圆角胶囊 + 圆形播放键 + 波形 + 时长；
- 时长按文本长度估算，点击播放 Azure TTS；
- 宽度随时长增加；
- 语音消息仍会后台预取，点击时优先命中缓存。

## 4. 图片

- 固定 220dp 宽、最大 260dp 高；
- 圆角 12dp，`ContentScale.Crop` 居中裁切；
- 不再 `fillMaxWidth()` 横向拉满。

## 5. 输入区

- 底栏白底 + 阴影；
- 图片/文件/语音按钮单独一行；
- 输入框 + 发送按钮单独一行，避免挤压。
