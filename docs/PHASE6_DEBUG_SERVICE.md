# DS-Mobile 调试服务记录（SSH/SFTP）

> 日期：2026-10-25

## 已实现

| 项 | 状态 |
|---|---|
| SSH/SFTP 端口 | `8022` |
| 用户名 | `dsmobile` |
| 登录方式 | 随机密码 |
| 文件根目录 | App `filesDir`（虚拟文件系统） |
| 局域网 IP | 自动显示 |
| 自动关闭 | ✅ 30 分钟后 `stopSelf()` |
| Android 兼容 | ✅ K60 实测可登录/传文件 |

## 安全边界

- 只在局域网使用；
- 默认 30 分钟自动关闭，避免长期暴露；
- 公钥登录暂未启用：当前 MINA 版本在 K60 上会破坏 KEX，保留密码登录；
- 下一步补 FTPS 2121 或只保留 SFTP。
